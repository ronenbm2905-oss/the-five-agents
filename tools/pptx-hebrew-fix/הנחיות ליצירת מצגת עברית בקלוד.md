# איך לבקש מקלוד מצגת עברית שלא תתעוות ב-PowerPoint

**הדבק את הבלוק שבהמשך בכל בקשה למצגת עברית.**

## למה זה נדרש

כשמבקשים מצגת עברית בלי הנחיה מפורשת, הפלט נוטה לשתי תקלות שנראות תקינות
בתצוגה המקדימה ונשברות ב-PowerPoint:

1. **RTL מדומה בתווי בקרה.** במקום להכריז על כיווניות כמאפיין של הפסקה,
   כל מחרוזת עברית נעטפת ב-`U+202B`/`U+202C` — תווי Unicode בלתי-נראים.
   ב-HTML זה עובד, ולכן זה "נראה בסדר". PowerPoint לעומת זאת מודד רוחב,
   שובר שורות ומציב פיסוק סביב תווים שלא אמורים להיות שם — והתוצאה מתעוותת.
2. **פונטים שלא קיימים במחשב היעד.** פונטים עבריים יפים כמו Heebo או
   Secular One הם Google Fonts. הם אינם מותקנים ב-Office תקני ואינם מוטמעים
   בקובץ, ולכן PowerPoint מחליף אותם בפונט אחר — עם רוחב אותיות שונה, מה
   שמזיז את כל הפריסה.

---

## הבלוק להדבקה

```
המצגת בעברית. שלוש דרישות טכניות מחייבות:

1. כיווניות RTL תוגדר כמאפיין פסקה בלבד: rtl="1" על כל <a:pPr>.
   אסור בתכלית האיסור להשתמש בתווי בקרה של Unicode לכיווניות —
   לא U+202B, לא U+202C, לא U+200E/200F, לא U+2066-2069.
   יישור לימין (algn="r") אינו תחליף ל-rtl="1"; צריך את שניהם.

2. כל ריצת טקסט עברית תסומן lang="he-IL" (לא en-US) —
   אחרת PowerPoint לא בוחר את פונט ה-complex-script לעברית.

3. פונטים: רק פונטים שמותקנים בכל Office ויש בהם עברית —
   Arial, Tahoma, David, Narkisim, Calibri.
   לא Heebo, לא Secular One, לא שום Google Font,
   אלא אם הפונט מוטמע בקובץ עצמו.

לפני שתסיים, בדוק שבקובץ אין אף תו מהטווחים שלמעלה,
ושכל פסקה עברית נושאת rtl="1".
```

## בדיקה מהירה אחרי שקיבלת את הקובץ

```bash
# צריך להחזיר 0. כל מספר אחר = התקלה חזרה.
python3 -c "
import zipfile,sys
z=zipfile.ZipFile(sys.argv[1])
n=sum(z.read(p).decode('utf-8').count(c)
      for p in z.namelist() if p.endswith('.xml')
      for c in '‪‫‬‭‮‎‏')
print('תווי בקרה:', n)
" deck.pptx
```

אם חזר מספר גדול מאפס — `fix.py` שבתיקייה הזו מתקן את הקובץ בפקודה אחת:

```bash
python3 fix.py deck.pptx fixed.pptx --swap-fonts
```
