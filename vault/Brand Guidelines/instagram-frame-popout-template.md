# Instagram Frame Pop-Out Template

## Overview
תבנית prompt חוזרת ליצירת דיוקן אופנה פוטוריאליסטי בתוך מסגרת פוסט אינסטגרם לבנה,
עם אפקט 3D pop-out (הדמות בוקעת מהמסגרת). התבנית פרמטרית: לוק/בגד, צבע רקע נגזר,
טקסט UI (likes / username / caption), ובחירת פוז מתוך ארבע אפשרויות —
Grip / Kiss / Resting / Dynamic Frame. היצירה רצה דרך הסקיל [[gpt-image-gen]]
(`/v1/images/generations`, מודל `gpt-image-2`), והתוצרים נשמרים ב-`yuval/Outputs/`
לצד קובץ `.txt` עם ה-prompt המלא לאיטרציה.

**הרחבת scope (2026-09-10):** הקובץ מכסה כיום לא רק את תבנית ה-pop-out אלא את
כלל **הקומפוזיציות מבוססות תמונת-ייחוס** שמופקות דרך `edit_image.sh`
(`/v1/images/edits`) — כולל תבנית **Photo Box** (רצועת photobooth אנכית בת 4
פריימים) ושילוב **לוגו של מותג חיצוני** כתמונת ייחוס שנייה. הלקחים על שימור
זהות, סדר ה-`image[]` וניסוח שלילות משותפים לכל התבניות ולכן יושבים כאן.
שם הקובץ נשמר כפי שהוא כדי לא לשבור wikilinks קיימים.

## Open Questions
- הלוגו של עירוני קריית אונו משוחזר טוב במבנה, בצבע ובטקסט העברי, אבל כתב היד הלבן שבתוך הכדורסל יוצא ג'יבריש — לא נבדק אם ניסוח ממוקד יותר או לוגו ברזולוציה גבוהה פותרים.
- `gpt-image-2` לא תומך ב-`input_fidelity`, והפרמטר הוסר מהסקריפט — לא ידוע אם קיים פרמטר חלופי כלשהו לשליטה ברמת שימור הפנים.
- אין דרך ידועה לבצע edit **נקודתי** (pixel-perfect) — כל edit מרנדר מחדש את התמונה כולה ומגריל פרטים עדינים. לא נבדק אם `mask` פותר את זה.
