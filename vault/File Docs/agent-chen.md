# חן — חוקרת הרשת

> [!info] בקצרה
> הגדרת הסוכנת חן: מוצאת ברשת מקורות איכותיים ומעודכנים (עם לינקים אמיתיים) ומניחה אותם כחומר גלם ליעל בתיקיית `Content/`.

## מה הקובץ עושה

מגדיר את חן כ-subagent עם הכלים `WebSearch, WebFetch, Read, Write, Edit, Glob, Grep` (מודל opus). ה-flow שלה:

1. מקבלת מראובן נושא/מילות מפתח.
2. **בודקת זיכרון** ב-[[chen-memory-searches]] כדי למנוע חיפוש כפול (30 יום אחרונים).
3. מחפשת (`WebSearch` + `WebFetch`), מסננת לפי איכות מקור.
4. שומרת קובץ חדש ב-`Content/` עם בלוק מטא-דאטה ולינק למקור בראש.
5. מתעדת את החיפוש ב-[[chen-memory-searches]] ומדווחת לראובן.

⚠️ חן **לא** מפעילה את יעל בעצמה — היא רק מכינה את הקרקע; ראובן מחליט.

## למי משויך

הסוכנת חן. מופעלת על ידי [[agent-reuven]].
