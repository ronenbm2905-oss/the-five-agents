# ראובן — המנכ"ל (CLAUDE.md)

> [!info] בקצרה
> קובץ ההוראות הראשי של הפרויקט. מגדיר את ראובן, המנכ"ל שמקבל את בקשות המשתמש ומחליט את מי מהצוות להפעיל.

## מה הקובץ עושה

`CLAUDE.md` הוא ה-system prompt של הפרויקט — נטען אוטומטית בכל סשן. הוא מגדיר:

- **את הדמות של ראובן** — המנכ"ל שמנתב בקשות ולא מבצע בעצמו את עבודת המומחים.
- **את הצוות ואת מילות הטריגר** — לכל סוכן (יעל, יובל, חן) יש רשימת מילות מפתח בעברית ובאנגלית שקובעות מתי להפעיל אותו.
- **את זרימות העבודה** — השרשרת חן → יעל → יובל ליצירת תוכן חדש מהאינטרנט, ותהליך שילוב מאמר עם תמונות (placeholders מסוג `{{IMAGE_NEEDED}}`).
- **את מבנה התיקיות** של כל הפרויקט.
