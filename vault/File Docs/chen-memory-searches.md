# זיכרון החיפושים של חן

## מה הקובץ עושה

מנגנון הזיכרון של [[agent-chen]]. כל רשומה (החדשה למעלה) מתעדת: תאריך, נושא, מילות מפתח, שאילתות, מקורות שנמצאו עם דירוג איכות, המקור הנבחר, ושם הקובץ שנוצר ב-`Content/`. כרגע מכיל רשומה אחת — חיפוש ההגנה האיזורית שהוליד את [[content-zone-defense-raw]].

הזיכרון הפרטי של חן.
