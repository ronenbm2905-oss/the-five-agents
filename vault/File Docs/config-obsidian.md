# .obsidian/ — הגדרות אפליקציית Obsidian

> [!info] בקצרה
> תיקיית ההגדרות של Obsidian בשורש הפרויקט. נוכחותה הופכת את הפרויקט כולו ל-Obsidian vault.

## מה הקובץ עושה

מכילה את קבצי התצורה של אפליקציית Obsidian:

- `app.json` — הגדרות כלליות של ה-vault.
- `appearance.json` — ערכת נושא ומראה.
- `core-plugins.json` — התוספים המובנים הפעילים.
- `graph.json` — הגדרות תצוגת הגרף.
- `workspace.json` — מצב חלונות/לשוניות אחרון.

בזכות קובצי `[[wikilinks]]` שבפתקי [[File Docs]], תצוגת הגרף של Obsidian תשקף את קשרי-הגומלין בין קבצי הפרויקט.
