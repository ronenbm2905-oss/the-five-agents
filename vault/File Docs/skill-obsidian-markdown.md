# סקיל obsidian-markdown

> [!info] בקצרה
> יצירה ועריכה של Obsidian Flavored Markdown — wikilinks, embeds, callouts, properties (frontmatter), tags ותחביר ייחודי אחר.

## מה הקובץ עושה

מכסה את ההרחבות הייחודיות של Obsidian מעבר ל-CommonMark/GFM: `[[wikilinks]]`, embeds (`![[...]]`), callouts (`> [!info]`), properties ב-frontmatter, תגיות, הערות ועוד. משמש בכל עבודה על קבצי `.md` בתוך vault — כולל הפתקים ב-[[File Docs]] עצמם.

מקורו בריפו [ZeremItay/the-5-agents-obsidian](https://github.com/ZeremItay/the-5-agents-obsidian).

## למי משויך

כלי כללי (tooling) — זמין לכל הצוות. שימושי במיוחד לתחזוקת ה-vault הזה.
