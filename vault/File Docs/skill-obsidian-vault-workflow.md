# סקיל obsidian-vault-workflow

> [!info] בקצרה
> אוכף את פרוטוקול הקריאה/כתיבה החובה מול ה-vault: קריאת קובץ הנושא בתחילת כל משימה, ואיפ־דייט מתוארך בסופה.

## מה הקובץ עושה

מגדיר את פרוטוקול הזיכרון ארוך-הטווח של הפרויקט תחת `vault/`:

- **Phase 1 (לפני משימה):** זיהוי הנושא, איתור קובץ הנושא דרך `_index.md`, קריאתו במלואו, וקריאת Meeting Notes / Content Briefs / Brand Guidelines רלוונטיים.
- **Phase 2 (אחרי משימה):** בחירת תיקייה, עדכון Overview במידת הצורך, עדכון Open Questions, הוספת רשומת Session Log מתוארכת עם `[status]` ו-`[[wikilinks]]`, ואימות בקריאה חוזרת.

מגדיר את התיקיות: `Meeting Notes/`, `Content Briefs/`, `Publishing Log/`, `Brand Guidelines/`, כל אחת עם `_index.md`.

מקורו בריפו [ZeremItay/the-5-agents-obsidian](https://github.com/ZeremItay/the-5-agents-obsidian). **המשתמש ביקש להפעילו בתחילת כל סשן ובכל פקודה.**

## למי משויך
