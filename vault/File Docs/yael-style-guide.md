# מדריך הסגנון של יעל

> [!info] בקצרה
> קובץ שלד להנחיות הסגנון של הצוות. יעל קוראת אותו בתחילת כל משימה וכותבת לפיו.

## מה הקובץ עושה

מגדיר את הטון, הקול, אורך המשפטים, מילים מועדפות/אסורות, מבנה כותרות ופתיח/סיום. רוב הסעיפים עדיין ריקים (שלד) — ואז [[agent-yael]] כותבת לפי שיקול דעת מקצועי. סעיף אחד **פעיל ומחייב**:

> [!important] עיצוב כותרות HTML
> כל הכותרות (h1–h3…) בכל תוצר HTML חייבות להיות אדומות — `#c62828`, כמשתנה CSS `--heading`.
