# תיקיית Outputs — תמונות מוגמרות

כאן יובל שומר את התמונות שהוא יוצר. לכל תמונה נשמרים **שני** קבצים בעלי אותו שם:

- `<YYYY-MM-DD>-<slug>.png` — התמונה עצמה.
- `<YYYY-MM-DD>-<slug>.txt` — ה-prompt ששימש ליצירתה, לצורך איטרציה.

לדוגמה:

```
2026-07-07-hero-banner.png
2026-07-07-hero-banner.txt
```
