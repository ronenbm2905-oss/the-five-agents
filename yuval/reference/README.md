# תיקיית reference — תמונות השראה לסגנון

כאן נשמרות תמונות השראה (`.png` / `.jpg` וכו') שמגדירות את השפה הויזואלית
של הצוות. יובל סורק את כל הקבצים בתיקייה זו בתחילת כל בקשת תמונה, ולומד מהם
את הסגנון, פלטת הצבעים, הקומפוזיציה והאלמנטים הויזואליים החוזרים.

הוסיפו כאן ככל שתרצו דוגמאות — ככל שיהיו יותר, כך התמונות שיובל יוצר יהיו
עקביות וקרובות יותר לשפה הויזואלית שלנו. אם התיקייה ריקה, יובל מעצב לפי
שיקול דעת מקצועי.

## נכסי מותג בתיקייה (לא השראה — שימור מדויק)

חלק מהקבצים כאן הם **לוגואים**, ואליהם מתייחסים אחרת: לא לומדים מהם סגנון,
אלא מצרפים אותם לתוצר **כמו שהם**. ב-prompt יש לכתוב סקשן `LOGO REFERENCE`
מפורש שאוסר לצייר מחדש, לתרגם, לצבוע מחדש או להמציא את הלוקאפ.

| קובץ | מותג | הערה |
|---|---|---|
| `logo-amr.png` | **א.מ.ר** — מערכת ניהול לעסקים קטנים | הלוגו הפעיל של הצוות. המקור הווקטורי ב-`yuval/brand/` — ראו `vault/Brand Guidelines/amr-brand-identity.md` |
| `logo-maniv.jpg` | החברה לניהול נדל״ן מניב | באנר, לא לוגו נקי. יש לקחת רק את ה-lockup ולזרוק את הרקע, הגל והגרדיאנט |

שים לב: כשמזינים כמה תמונות ייחוס ל-`edit_image.sh`, הקישור בין התיאור לתמונה
הוא **סדר הקבצים** (`FIRST` / `SECOND`), לא שם הקובץ.
